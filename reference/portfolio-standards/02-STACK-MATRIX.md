## Compatibility policy

- Baseline runtime: Node.js 24 LTS, pinned in `.nvmrc`, `engines`, and CI.
- Package manager: pnpm through Corepack with an exact `packageManager` field and committed lockfile.
- Exact package patch versions are resolved when a repository starts and recorded in `docs/toolchain.lock.md`.
- XState 5 requires TypeScript 5 or newer.
- PrimeVue design tokens are mapped through a custom preset; premium templates are never required.
- Quasar projects use `@quasar/app-vite` modes and do not introduce a separate hand-maintained Vite configuration.
- Tailwind CSS 4 projects use the official Vite plugin or the framework-supported integration.
- MediaPipe, OpenCV.js, model files, WASM files, and generated clients are checksum/schema pinned.
- Nuxt is reserved for Satin and optional integration fixtures/modules.
